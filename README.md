# Scientifica — 3D Science Exhibition Guide

Scientifica is an interactive, 3D spatial map and scheduling application for the NPS Yeshwanthpur Annual Science Exhibition 2026. This project utilizes a modern React/Vite architecture combined with Three.js to render a highly interactive, premium 3D experience with a glassmorphism UI.

## Architecture

This project is built using:
- **React (v19)**: For the 2D user interface (Elevator, Drawers, Headers, Filters).
- **Vite (v8)**: For ultra-fast bundling and development.
- **Three.js (r186)**: For rendering the 3D architectural exhibition model, quadrangle cutouts, and procedural mockups.
- **Tailwind CSS (v4)** + **tw-animate-css**: For rapid utility-first UI styling, glassmorphism effects, and entrance animations.
- **Vitest**: Unit tests for the routing engine, tour planner, live status and data integrity.

## Running the Application

### Development Mode
To run the app with Hot Module Replacement (HMR):
```bash
npm install
npm run dev
```

### Production Build
To build the application for deployment:
```bash
npm run build
```

### Local Testing Server
To test the production build on your local network (e.g., to view on a mobile phone):
```bash
npm run build
node server.cjs
```
The server will run on port `8080` and serve the compiled `/dist` directory.

### Tests & Typechecking
```bash
npm test        # Vitest unit suites (routing, tours, data integrity, live status)
npm run lint    # Strict TypeScript check (tsc --noEmit)
```

## 3D Coordinate System & Building Specs
- **Scale:** 1 Three.js unit = 1 meter.
- **Floor Slab Size:** 46m (Width, X-axis) × 42.5m (Depth, Z-axis), plus a 16m × 6m covered entrance stage.
- **Floor Gap:** 6.5m between levels (Y-axis), basement at Y = 0.
- **Quadrangles:** Two open-air courtyards (Big Quad and Small Quad) span through the upper floors.
- **Staircases:** Three staircases (West, East/Central) connect the floors, defined in `data.ts`.
- **Origin:** DXF center (X=23.00m, Y=21.25m); transform `x = X − 23.00`, `z = −(Y − 21.25)`.

## UI/UX Features
- **Cinematic Camera:** Smooth parabolic arcs calculated using OrbitControls.
- **Interactive Raycasting:** Click/touch support on all 3D rooms to trigger the React `ExhibitDrawer`.
- **Glassmorphism:** Elegant, modern translucent panels with backdrop blur + vibrancy.
- **Guided Tour Mode:** Automated cinematic flying between featured exhibits, ordered by a
  nearest-neighbor walking heuristic so visitors loop a floor instead of zigzagging.
- **Directions:** Corridor-graph shortest paths with orthogonal routing and stair transitions.
- **Deep links:** The URL hash mirrors the current room (`#exhibit=g_stage`) — shareable via QR code.
- **Live status:** On the event day, exhibit badges (Live Now / Starts Soon / Finished) are
  computed from the actual clock instead of static labels.
- **Search:** Ranked, typo-tolerant search (`/` to open).
- **Offline-first PWA:** Service worker caches the app shell for crowded exhibition Wi-Fi.
- **Accessibility:** Keyboard shortcuts (floor keys, arrow keys cycle rooms, Esc), reduced-motion
  and reduced-transparency support, visible focus rings.
